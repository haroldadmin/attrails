# Contributing

Thanks for your interest in ATTrails! Bug reports, ideas, and pull requests are welcome.

## Guidelines

- We request contributors to always open an issue before submitting a pull request. We want to ensure that everyone works in a direction that is aligned with the project's vision.
- You may use LLMs to submit contributions, but we require you to fully understand, own, and stand behind the code you submit. Low quality, sloppy and spammy contributions will not be accepted.
- Please be respectful and polite with the maintainers and other contributors in the project.
