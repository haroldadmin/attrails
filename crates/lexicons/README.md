# lexicons

This crate contains lexicon definitions and their generated code using [`lex-fetch`](https://docs.rs/jacquard-lexgen/latest/jacquard_lexgen/).
See the [lexicons.kdl](../../lexicons.kdl) for the configuration.

Most of this package code is autogenerated. Lexicon regeneration might lead to large git diffs.
The `sources`[./sources] contains non-generated lexicon definitions for data types related to ATTrails.
